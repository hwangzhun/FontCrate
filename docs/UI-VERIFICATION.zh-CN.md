# 界面优化验收

本次继续使用 WPF-UI 4.3.0，不改数据库和字体扫描、安装机制。

## 自动检查

```powershell
dotnet build src/FontCrate.App/FontCrate.App.csproj
dotnet test tests/FontCrate.Tests/FontCrate.Tests.csproj
dotnet run --project tools/FontCrate.ManagementVerify/FontCrate.ManagementVerify.csproj
```

最后一项需要 Windows WPF 运行环境，使用隔离数据库和模拟字体平台，不修改系统字体。
覆盖来源/标签查询独立性、选择恢复、宽窄布局切换、列表/预览切换、预览文字独立性和字号校验。
`--skip-layout` 不代表视觉验收通过。

## Windows 人工验收（尚待执行）

分别在浅色和深色主题下检查 1050×700、1200×800、1400×960 DIP 窗口，以及 100%、150%、200% 系统缩放。显示器必须有足够的逻辑工作区容纳目标窗口。

- 导航在窗口宽度小于 1200 DIP 时默认折叠；字体库工作区小于 900 DIP 时进入单栏，预览开关和返回列表均可通过键盘访问。
- 来源/标签工作区小于 800 DIP 时可切换列表与详情；切换和跨断点缩放后搜索、选中项及关联字体选择保持。
- 拖动字体库分隔线后缩放窗口，验证分栏比例保留；收起和重新显示预览后比例恢复。
- 短窗口下可滚动访问预览样例、字号、完整字体详情和文件定位；不出现内容被永久裁切的情况。
- 首次空库显示添加目录；已有来源但无字体显示管理来源；筛选无结果显示清除筛选；加载阶段不会闪现首次空库提示。
- Ctrl/Shift 多选后操作栏出现；菜单中停用、卸载、标签分配、导出均沿用原有行为和确认。退出多选后不会残留标签编辑区。
- 已安装、临时启用及来源不可用状态可并列；明暗主题均有可读文字，不能仅靠颜色辨别。
- 预览样例不改列表文字；“使用列表文字”只复制一次。字号输入空值、NaN、7、193 后恢复此前有效字号；8、192 可接受。
- 部分成功、失败、取消的结果摘要与完整日志一致；未知数量不显示成零，未完成数量不并入失败数。恢复/检查来源入口可用。
- 使用至少 10,000 个字体的大库，连续滚动、调整分栏和反复筛选；确认没有全量生成行控件、滚动明显卡顿或缩略图错位。多选和筛选后选择恢复正常。
- 全程检查 Tab 顺序、可见焦点、Enter/Space 操作、工具提示和主题切换后的预览更新。

## 本次环境验证边界

Linux 环境可以编译 Windows 目标及运行跨平台单元测试。原生 Windows 的布局、DPI、键盘焦点及大字体库性能尚未实机验收；编译成功不能替代这些检查。
