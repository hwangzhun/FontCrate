# FontCrate 详细使用说明

作者：**Hwangzhun** · 项目许可证：**GNU GPL v3（GPL-3.0-only）** · [GitHub](https://github.com/hwangzhun/FontCrate/)

面向 Windows 10 1809+ / Windows 11 x64 的轻量字体管理工具，使用 C#、.NET 10、WPF UI 4.3.0、SQLite 与 DirectWrite。它独立实现字体管理功能，不使用 MainType 的 DLL、服务或授权逻辑。

## 当前状态

界面改版代码和新版 Windows 自包含安装包已经生成。Linux 环境完成了 Release 编译（零警告、零错误）和 97 个自动化测试（核心、分类管理状态、主题设置及预览缓存键）；此前完成了 360 个真实字体文件 / 392 个 face 的元数据解析检查。

**尚未完成 Windows 原生验收**：WPF 界面、DirectWrite/WIC 实际渲染、GDI 跨应用启用、HKCU 安装、Word 兼容性和 Windows 性能指标均需按 [安装版验收清单](INSTALLER.zh-CN.md) 验证。安装包目前是待验收构建，不应理解为这些检查已经通过。

## 运行

运行 `FontCrate-Setup-<版本>-win-x64.exe` 完成安装，从开始菜单或可选桌面快捷方式启动。默认仅安装到当前用户的 `%LOCALAPPDATA%\Programs\FontCrate`，运行时已封装进单文件 EXE，安装目录不再散落 DLL，也不安装 Markdown 文档；不需要另行安装 .NET，也不要求管理员权限。

升级或卸载前，请从程序或托盘选择“退出并停用临时字体”。卸载只移除安装文件与快捷方式，字体库、设置、原始字体和已安装到当前用户的字体都会保留。安装包目前未签名，可能出现 SmartScreen 提示；构建与验收步骤见 [安装版说明](INSTALLER.zh-CN.md)。

1. 点击“添加目录”，选择字体所在文件夹；程序会扫描该来源。
2. 左侧导航提供字体库、来源管理、标签、任务与结果、设置五个页面。字体库顶部按来源、标签、收藏或状态筛选，并搜索字体家族、风格、完整名称及 PostScript 名称；“清除筛选”恢复全部字体。
3. 列表上方的“列表预览”输入框可设置所有行的预览内容（最多 256 个字符），与右侧大预览独立；修改后只刷新可见行。类型列按文件扩展名显示 TTF、OTF、TTC、OTC 等，离线来源仍可显示已索引文件的类型。中间列表连续显示全部匹配字体，无需翻页，支持 Ctrl / Shift 多选；底部显示总数与选中数量。同一筛选条件下刷新会保留多选和滚动位置，改变搜索或筛选会回到列表顶部。
4. 列表与右侧大预览默认按 70% / 30% 分配宽度，可拖动分隔线调整。预览默认 48 px，支持 8–192 px；修改预览文字或面板宽度会重新渲染。字体详情和文件位置可展开，字符网格保留每批 64 个字符的翻页。
5. “标签”管理页可直接搜索、新建、改名和删除，列表右侧显示关联字体数量（包含来源不可用的字体）。新建无需选中字体；名称为 1–100 个字符，同类不能重名。搜索名称只影响管理页列表，当前字体筛选会保留，“全部”入口始终可用。选中一个或多个字体后，展开“标签”，选择已有标签并点击“添加到选中字体”或“从选中字体移除”。删除需确认，只清理该项目及其关联，保留字体文件和其他标注。
   在字体库可直接右键字体，选择“添加到标签”，也可选择“新建标签…”。右键已选字体保留多选，右键其他字体则只选中该字体。新建标签和添加关联同时保存。
6. 用“临时启用”提供字体给其他软件，用“停用临时字体”撤销本工具的临时启用，保留原文件和持久安装；用“安装”持久安装到当前用户，用“卸载已安装字体”移除本工具持久安装的副本与注册。操作会列出实际影响的 face；TTC/OTC 必须按整个文件操作。
7. 在“来源管理”页执行增量扫描和校验重扫；在“任务与结果”页查看扫描错误和最近操作结果，或核对与恢复状态。扫描与字体操作期间自动显示进度弹窗和取消入口。
8. 在“设置”页选择跟随系统、浅色或深色。选择保存在 `%LOCALAPPDATA%\FontCrate\settings.json`；缩略图、大预览和字符网格同步改变底色及字形颜色。设置缺失或损坏时安全回到跟随系统。升级已有 FontLite 数据时会继续使用原目录，保留字体库、分类和设置。
9. 关闭主窗口时可以选择完全退出、最小化到托盘或取消。完全退出会先等待任务收尾并停用临时字体。设置页或托盘中的“退出并停用临时字体”会停止本工具的临时字体；持久安装继续保留。

页面切换保留筛选、搜索、多选、列表滚动和预览设置；管理页的搜索和选择独立于字体库；只有“在字体库查看”才切换字体库的对应筛选。窗口小于 1200 像素宽时导航缩为图标栏，默认 1400×960、最小 1050×700。

字体状态用灯表示：蓝色为已安装，绿色为临时启用，橙色为来源不可用，灰色为未安装且未启用。状态可同时存在，悬停灯区查看完整说明；重复字体额外显示可用位置数量。

扫描与字体操作开始时自动显示 WPF-UI 原生 ContentDialog 进度弹窗，任务期间暂停其他界面操作，任务和列表刷新结束后自动关闭；底部仅显示简洁状态，详细结果留在“任务与结果”页。临时启用使用 2–8 个并发工作线程，按处理器数量自动选择，批内同名不同内容按选择顺序检查冲突。目录枚举时总数未知，显示动态进度条；枚举结束后显示当前来源的百分比、处理数量和错误数。批量启用、停用、安装和卸载按去重后的文件计数，TTC/OTC 的多个 face 只算一个文件。状态核对与恢复使用动态进度条。取消任务保留实际进度，任务状态灯区分处理中、完成、取消或需处理、失败。

新增或修改文件后在“来源管理”页点击“增量扫描”。它按大小和修改时间跳过未变文件；如果怀疑内容变了但时间未变，请用“校验重扫”。首版采用手动刷新，不持续监控所有目录。

## 数据与操作边界

- 新安装默认数据：`%LOCALAPPDATA%\FontCrate\library.db`；预览只缓存于内存，上限 64 MiB。
- 原始字体默认不复制。临时启用副本位于应用的 `temporary-fonts` 目录；安装副本位于当前用户的 Windows Fonts 目录。
- 同内容、多路径合并为同一个逻辑 face；同名不同版本保留独立记录。重复提示仅展示位置，不自动删除。
- 升级时自动将旧合集转换成标签，同名标签合并字体关联，空合集也保留为标签；迁移失败会整体回滚。改名保留 ID 与关联，移除关联后空项仍可继续使用。
- 移动文件后重扫相同内容会保留标签和收藏；移除来源不会删除原文件或用户标注。
- 卸载仅处理本工具安装、且内容和注册项仍匹配的字体。已有系统字体只读取状态，不自动覆盖或卸载。
- “已安装”筛选作用于已索引的字体。若要浏览所有系统字体，可添加 `%WINDIR%\Fonts` 及 `%LOCALAPPDATA%\Microsoft\Windows\Fonts` 为来源。
- 停用失败时保持程序运行，保留副本和操作记录，关闭使用字体的软件后重试。异常退出后启动时核对操作记录，不自动重新启用临时字体。
- 界面异常会记录到数据目录的 `performance.jsonl`，便于定位问题。
- 操作结果和扫描错误在“任务与结果”页显示；“核对与恢复状态”可重试未完成操作。
- 某些应用会缓存字体列表，可能需要关闭并重新打开。首版不清理第三方字体缓存。

变量字体使用默认实例，不提供轴调节；字符覆盖表示 Unicode 字符映射，不等同于完整语言排版支持。类型识别可识别 WOFF/WOFF2 扩展名，但目前扫描与预览只支持 TTF/OTF/TTC/OTC；WOFF/WOFF2 解析、Type 1、位图字体、云同步和系统级安装不在当前范围内。

## 开发与构建

在 Windows 上安装 .NET 10 SDK；生成安装包还需要 Inno Setup 6.5 或更高版本；可使用支持 .NET 10 的 Visual Studio，或直接执行：

```powershell
dotnet build FontCrate.sln -c Release
dotnet test tests/FontCrate.Tests/FontCrate.Tests.csproj -c Release
dotnet run --project src/FontCrate.App
powershell -ExecutionPolicy Bypass -File tools/publish.ps1
```

Linux 可以运行核心测试，并交叉编译 WPF 项目；运行 WPF 和原生验证程序需要 Windows。

```bash
dotnet test tests/FontCrate.Tests/FontCrate.Tests.csproj -c Release
dotnet build FontCrate.sln -c Release
```

项目分为 Core（索引、数据库、扫描、可测试的字体操作状态机）、Windows（DirectWrite、WIC 和 Win32 适配）、App（WPF / MVVM）及 Verify（Windows 验证程序）。

仓库的 `.github/workflows/windows.yml` 提供 Windows 构建、测试和打包；实际运行结果请查看 GitHub Actions。关于页的 GitHub 按钮指向 FontCrate 项目仓库。

## 来源、标签管理

来源页左侧搜索目录名称或路径，右侧展示完整路径、最近扫描的可用状态、按内容去重的文件数、字体面数量和字体列表。增量扫描和校验重扫只处理所选目录，“扫描全部来源”处理全部目录。可打开目录或跳转字体库；移除来源仅删除索引位置。离线来源仍保留原统计和分类标注。

标签页保留自己的搜索、选择和滚动状态。选中分类后可以搜索、预览关联字体，使用 Ctrl / Shift 多选并移除关联。通过“添加字体”弹窗从已有字体库选择，已关联字体自动排除；新建与重命名使用原生对话框。删除分类不会删除字体文件或其他分类关联。

两页的左右面板随窗口高度伸缩，各自独立滚动。长列表启用虚拟化，缩略图只在条目可见时生成。来源不可用的字体仍可管理分类，预览区会说明无法预览的原因。


## 字体文件导入与导出

- 在字体库列表右键选择“导入字体…”，可多选 TTF、OTF、TTC、OTC 文件；空白处和空列表也能使用。字体复制到应用数据目录的 `ImportedFonts`，按内容去重并自动纳入字体库；原文件保留，之后移动或删除原文件不影响已导入副本。导入不会自动安装或启用字体，也不支持 ZIP。
- 选中字体后右键选择“导出所选字体…”。一个字体文件可指定保存文件名；多个文件可选择导出目录，同名文件自动编号。相同内容只导出一次，TTC、OTC 保留完整集合文件。
- 在“标签”页选中标签，点击“导出全部字体…”，将该标签的全部字体保存为 ZIP。当前字体搜索和选中行不影响导出范围；空标签不可导出。压缩包只包含字体文件，不附带标签或收藏数据。
- 导出前校验来源内容；不可用或已变化的字体会跳过并显示原因。任务支持进度和取消，已完成的独立文件或已导入副本会保留；未完成的文件和 ZIP 会清理，已有目标 ZIP 在新包成功完成后才替换。部分成功和失败详情可在“任务与结果”查看。
