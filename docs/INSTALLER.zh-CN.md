# FontCrate 安装版

发布形式为 Windows 10 1809+ / Windows 11 x64 EXE 安装包，不再发布免安装运行 ZIP。应用以自包含单文件 EXE 发布，托管库、原生库及 .NET 运行时统一封装，安装目录不再散落 DLL；无需单独安装 .NET，也无需管理员权限。

最低版本为 Windows 10 1809（系统内部版本 17763），仅提供 x64 安装包。该下限兼顾当前用户字体安装和现有 DirectWrite 接口；不支持 Windows 7 / 8 / 8.1。Windows 10 与 Windows 11 的实际运行均需分别验收。Windows 版本能否安装与微软是否仍提供系统及 .NET 支持是不同事项；请优先使用仍获安全更新的系统。

## 安装、升级与卸载

- 运行 `FontCrate-Setup-<版本>-win-x64.exe`，可选择简体中文或英文安装界面。
- 默认安装位置是 `%LOCALAPPDATA%\Programs\FontCrate`。创建开始菜单快捷方式，可选桌面快捷方式与安装后立即启动。不设置开机启动，也不加入自动更新。
- 固定 `AppId=FontCrate`，后续安装器沿用之前的安装路径和卸载入口，支持覆盖安装。版本来自发布 EXE 的文件版本；不是根据安装脚本手填版本。
- 升级、安装及卸载前完全退出应用，包括托盘。选择“退出并停用临时字体”，等待完成。安装器通过运行互斥量阻止修改正在使用的程序，不强制关闭 FontCrate。
- 用户数据仍位于 `%LOCALAPPDATA%\FontCrate`；已有旧 FontLite 数据时沿用原目录。卸载仅删除安装文件及快捷方式，保留数据库、分类、设置、字体原文件和用户已安装的字体。重新安装后可以继续使用原字体库。
- 安装包目前不签名，Windows SmartScreen 可能提示未知发布者。源码 ZIP 和 SHA256 校验文件随安装包提供；代码签名需另行配置证书。

## Windows 构建

安装 .NET 10 SDK 和 [Inno Setup 6.5+](https://jrsoftware.org/isdl.php)（简体中文语言文件已随仓库提供），在仓库根目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File tools/publish.ps1
```

支持自定义输出目录或编译器路径：

```powershell
./tools/publish.ps1 -Output ./artifacts -IsccPath 'C:\Program Files (x86)\Inno Setup 6\ISCC.exe'
```

脚本在临时空目录完成自包含单文件发布、包内依赖及语言检查、安装包编译及源码打包。关闭裁剪，保留内嵌调试符号用于错误堆栈；语言资源只保留简体中文（zh-Hans）及英文，框架默认英文资源内置。安装目录只有 FontCrate.exe 和安装器生成的卸载文件，不安装 Markdown、松散 DLL 或语言目录。项目许可证及第三方声明内嵌，在设置页可查看；打开许可文件时按需导出到数据目录的 legal 文件夹。升级会清理旧版运行库与语言目录，用户数据仍单独保留。

单文件包含依赖，不等于没有依赖：原生库由 .NET 启动时解压到 `%TEMP%\.net` 下的缓存目录。日志、数据库和设置继续写入用户数据目录，不写入程序安装目录。

编译成功后才复制到输出目录：

- `FontCrate-Setup-<版本>-win-x64.exe`
- `FontCrate-source.zip`（包含安装脚本与 CI 配置）
- `SHA256SUMS.txt`（本次安装包及源码 ZIP 的 SHA256）

`-SkipTests` 仅供已经完成测试的 CI 使用。重复发布采用全新暂存目录，不会把旧 DLL 打包进安装器；输出目录已有的旧文件不会被批量删除，发布时只选本次校验清单中的文件。

## 验证范围

Windows CI 使用预装 Inno Setup，完成现有构建、核心测试、管理页与原生渲染验证，再编译安装包。`tools/test-installer.ps1` 在无既有安装的环境执行静默安装、运行互斥量阻挡、覆盖安装、开始菜单目标、依赖与语言资源检查、排除文件检查、用户数据保留与卸载检查。测试目录包含中文和空格；测试不会启动真实应用或启用系统字体。

CI 中的同版本覆盖安装不是跨版本升级验收，CI 主机也不是“未装 .NET 的标准用户 Windows 10 / 11”。以下项目仍需在可恢复的 Windows 10 1809+ / Windows 11 x64 测试机手动验收，不能由安装器编译成功推断已通过：

1. **系统版本**：分别在 Windows 10 1809、Windows 10 22H2 和 Windows 11 x64 验证以下项目；Windows 10 1803 及更早系统应被安装器拒绝。
2. **无 .NET、标准用户**：安装全过程无 UAC 管理员请求，中英文界面和卸载说明正确；开始菜单与桌面快捷方式均可启动，程序不提示缺少运行时。
3. **实际功能**：新建字体库，扫描字体，预览字形，保存标签与设置；托盘行为正常，临时启用及停用成功。
4. **运行中修改**：窗口打开及最小化托盘时，分别尝试安装、升级和卸载，均要求先退出；临时字体清理失败且程序保持运行时仍应阻止继续。
5. **升级与重新安装**：安装新版本，确认原字体库、分类和设置保留；卸载后原始字体和用户已安装字体保留；重新安装继续使用旧数据。另测旧 FontLite 数据目录。
6. **兼容路径**：中文用户名、含空格的默认及自定义安装目录；不支持的系统或架构提示后退出。
7. **发布文件**：核对版本、SHA256、对应源码和许可证；实际验证首次启动、字体渲染、跨应用启用和性能，记录结果。

不要在有既有 FontCrate 安装的机器执行静默冒烟脚本。安装日志复制到 `artifacts/installer-test-logs/`，CI 单独上传该目录；测试结束会清理临时安装目录。
